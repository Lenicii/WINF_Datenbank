# WINF_Datenbank
This project contains a simple database system for managing hardware in companies.
The goal is to retrieve information about lifecycles and assignments to employees.
Please note: 
Database implementation and example SQL queries are currently in developement and coming soon, estimated until 14th of June, 2026.

## Technologies
- Database design (ERM, Chen notation)
- Implementation with MariaDB (coming soon)
  
## Features
- management of active and inactive devices
- overview of maintenances
- SQL queries for analysis
